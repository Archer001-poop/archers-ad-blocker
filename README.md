## 🚀 How to Install (Step-by-Step)

Since this project is independent, you can load it directly into your Chromium-based browser (Chrome, Edge, Brave, Opera) from source code:

### 1. Download the Project Folder
1. Click the green **Code** button at the top right of this GitHub page.
2. Select **Download ZIP**.
3. Locate the file on your computer and extract the ZIP archive to your Desktop.

### 2. Install it via Developer Mode
1. Open a new tab in your browser and type: `chrome://extensions/`
2. Turn on the **Developer Mode** toggle switch in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select the extracted folder containing your code files.

🎉 **Done! Your custom ad blocker is fully active.**
